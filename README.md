# FlappyBird_21

Реализован похожий на Flappy Bird раннер со следующими изменениями:
1. Совершенно другая графика.
2. Вместо препятствий появляются ведьмы, которые перпеодически стреляют вперед (влево). Пули убивают игрока
3. Игрок тоже может стрелять по нажатию отдельной клавиши (ЛКМ). Пуля будет направлена туда, куда смотрит игрок в момент выстрела. Пули убивают ведьм
4. Так же добавлены забавные элементы (Например после каждой смерти цвет игрока рандомно меняется)
